## 基本原则

好的 Prompt 应该做到：

- **明确目标**：告诉模型你要什么，而不是你不要什么
- **提供上下文**：背景信息越充分，回答越准确
- **指定格式**：需要列表就说"用列表"，需要代码就说"用代码"
- **给出示例**：Few-shot 示例能显著提升输出质量

## 常用模式

### 角色设定

```
你是一位有 10 年经验的 TypeScript 工程师，请帮我审查以下代码...
```

### 思维链（Chain of Thought）

```
请一步一步分析这个问题，先列出你的思考过程，再给出结论。
```

### 结构化输出

```
请用以下 JSON 格式返回结果：
{
  "title": "标题",
  "summary": "摘要",
  "tags": ["标签1", "标签2"]
}
```

## 调试技巧

- 输出不符合预期时，先检查 Prompt 是否有歧义
- 复杂任务拆分成多个步骤，分轮对话完成
- 用"请重新思考"或"你确定吗"引导模型自我纠错

## 注意事项

- 避免在 Prompt 中包含敏感信息
- 长上下文时把最重要的信息放在开头或结尾
- 不同模型对 Prompt 的敏感度不同，需要针对性调整
