## Skills 平台

[Skills 开放平台](https://skills.sh/) 提供了一个从设计稿生成前端代码的技能包，可通过 Claude Code 安装：

```bash
npx skills add https://github.com/Zbcc07/agent-skills --skill frontend-code-generator-vue3
```
